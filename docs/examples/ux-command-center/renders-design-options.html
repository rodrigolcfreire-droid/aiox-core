OPCAO 02Grade de Cards

Thumbnail gigante domina cada card. Play overlay no hover, status no canto, duracao no rodape da thumb, chips Hook/Dev/CTA abaixo. Visual de biblioteca de videos.

Quando usar: creator que decide por imagem (frame inicial impacta mais que nome). Ganho: reconhecimento visual instantaneo + cabem 8-12 renders na primeira dobra. Trade-off: metadata fica comprimida, rating pequeno.

OPCAO 03Tabela Densa

Colunas fixas (thumb · hook · dev · cta · rating · dur · size · acoes), checkbox de bulk action, filtros rápidos, headers clicaveis pra sort. Visual de ferramenta profissional.

Quando usar: 50+ renders, power user que gerencia em lote. Ganho: 3x mais densidade que as outras opcoes + selecao multipla nativa. Trade-off: hostil pra iniciante, thumb pequeno reduz ID visual.

OPCAO 04Ranking Podium

Top 3 viram cards grandes (ouro/prata/bronze). Resto vai pra lista mini compacta. Força a decisao: "quem sobe pra escalar?" fica visivel em 2 segundos.

Quando usar: momento de decisao pos-batch — voce avaliou, agora precisa eleger vencedores. Ganho: hierarquia clara, fomenta competicao visual, direciona acao. Trade-off: se ninguem foi avaliado ainda, podium fica vazio e a tela parece quebrada.
